# Code Flux Landing

Build a premium, modern, responsive hackathon landing page for “CODE FLUX”, based heavily on the attached reference poster.

The website is for students who will visit the page to understand the event, explore the benefits, and register.

The design must feel like the poster has been transformed into a polished website — NOT a generic dark developer/hackathon website.

1. CORE DESIGN DIRECTION

Use the uploaded CODE FLUX poster as the primary visual reference.

Visual identity

 Background: clean white / very light gray

 Primary blue: #1264E8

 Green: #0A9F3D

 Orange: #FFA500

 Red: #F02020

 Main text: near-black / charcoal

 Secondary text: muted gray

 Thin light-gray borders

 Subtle shadows only

 Rounded cards and buttons

 Clean geometric layout

 Lots of whitespace

 Modern student-tech aesthetic

 Professional enough for a university event

 Avoid excessive gradients

 Avoid glassmorphism

 Avoid neon cyberpunk styling

 Avoid an all-black background

The website should visually communicate:

BUILD • BREAK • INNOVATE

17. REGISTRATION EXPERIENCE

Registration is the most important conversion action.

Every major section should have a REGISTER NOW CTA.

Buttons should scroll/open the registration form.

If using an external registration form, make the URL configurable through:

REGISTRATION_URL

Do not hardcode random URLs.

On mobile, add a sticky bottom REGISTER NOW button so students can register without scrolling back to the top.

19. RESPONSIVE DESIGN

The website must be fully responsive.

Desktop

Wide layout with generous whitespace.

Tablet

Reduce spacing and convert multi-column sections appropriately.

Mobile

Everything should stack naturally.

Hero:

CODE
FLUX

large but responsive.

Hero information blocks become vertical or 2-column.

Tracks become single-column cards.

Timeline becomes vertical.

Prize cards stack.

Navigation becomes hamburger.

Registration CTA remains highly visible.

No horizontal scrolling anywhere.

The final website should look like:

“The CODE FLUX poster turned into a premium interactive website.”
